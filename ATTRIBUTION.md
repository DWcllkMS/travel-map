# Атрибуция и используемые открытые данные

Данный проект использует исключительно открытые картографические, пространственные и мультимедийные источники данных, а также модели машинного обучения с чистыми открытыми лицензиями:

1. **Natural Earth**
   - Границы стран (`ne_10m_admin_0_countries_rus`), регионов (`ne_10m_admin_1_states_provinces`) и населённые пункты (`ne_10m_populated_places`).
   - Лицензия: Public Domain.
   - Ссылка: https://www.naturalearthdata.com

2. **Wikidata**
   - Русскоязычные наименования и метки административно-территориальных единиц (регионов и стран).
   - Лицензия: Creative Commons CC0 1.0 Universal (Public Domain Dedication).
   - Ссылка: https://www.wikidata.org

3. **geoBoundaries**
   - Границы административных районов России (`gbOpen/RUS/ADM2`).
   - Лицензия: Open Data Commons Open Database License (ODbL) / CC BY 4.0.
   - Ссылка: https://www.geoboundaries.org

4. **OpenStreetMap**
   - Административные границы и русскоязычные наименования районов (`admin_level=6`).
   - Копирайт: © Участники OpenStreetMap.
   - Лицензия: Open Data Commons Open Database License (ODbL).
   - Ссылка: https://www.openstreetmap.org/copyright

5. **OpenFreeMap / OpenMapTiles**
   - Базовая растровая и векторная подложка карты планеты (`https://tiles.openfreemap.org/planet`).
   - Лицензия: Open Database License (ODbL), стили на базе OpenMapTiles (CC-BY).
   - Ссылка: https://openfreemap.org

6. **AWS Terrain Tiles (Mapzen Terrarium)**
   - Цифровая модель высот (DEM) и рельеф местности (hillshade).
   - Лицензия: Open Database License (ODbL), ArcticDEM, SRTM, Mapzen.
   - Ссылка: https://registry.opendata.aws/terrain-tiles

7. **Hugging Face / Xenova CLIP**
   - Квантованная легковесная модель компьютерного зрения `Xenova/clip-vit-base-patch32` для сопоставления фото.
   - Лицензия: MIT License / Apache-2.0.
   - Ссылка: https://huggingface.co/Xenova/clip-vit-base-patch32

8. **Wikimedia Commons**
   - Геотегированные изображения для проверки фотографий без GPS.
   - Лицензии: Creative Commons (CC BY, CC BY-SA, Public Domain) с указанием автора и лицензии из метаданных медиафайла.
   - Ссылка: https://commons.wikimedia.org
