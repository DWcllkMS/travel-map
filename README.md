# 🗺️ Карта путешествий v1.4.0

Личная геймифицированная PWA-карта открытий и поездок. Вы загружаете фотографии или видеоролики из своей галереи, приложение локально определяет по координатам GPS, в каких регионах, районах и достопримечательностях вы побывали, рассеивает туман войны и начисляет опыт за исследованные уголки планеты.

Проект работает **на 100% локально** в вашем браузере: никаких серверов, никакой телеметрии или отправки медиафайлов. Все данные хранятся прямо в IndexedDB на вашем компьютере или телефоне.

Готовый сайт: **https://dwcllkms.github.io/travel-map/** — обновляется сам после каждого пуша в `main` (GitHub Actions → Pages).

## ⚡ Быстрый старт

### Требования
- **Node.js** версии 22+ (тесты чтения фото требуют 21+)
- **Python** 3.8+ (для вспомогательных скриптов запуска и доставки)

### Запуск на Windows
Двойной клик на `start.bat` или в терминале:
```cmd
start.bat
```
Чтобы открыть приложение на телефоне через локальную сеть Wi-Fi:
```cmd
start.bat --host
```

### Запуск на macOS и Linux (Ubuntu)
Сделайте скрипт исполняемым и запустите:
```bash
chmod +x start.sh
./start.sh
```
Для доступа со смартфона по Wi-Fi:
```bash
./start.sh --host
```

Скрипт автоматически проверит зависимости, установит недостающие пакеты, поднимет dev-сервер Vite, дождётся открытия порта и запустит ваш браузер по умолчанию.

## 📱 Установка как PWA на телефон

> На Android при выборе фото через галерею телефон стирает из них координаты. Выбирай фото кнопкой «Выбрать через „Файлы“» (папка DCIM/Camera) — так местоположение сохраняется.

1. Откройте опубликованный сайт (или локальный адрес по Wi-Fi) в Google Chrome или Safari на смартфоне.
2. В меню браузера выберите **«Установить приложение»** (на Android) или **«Поделиться» → «На экран „Домой“»** (на iOS).
3. Карта появится как полноценное нативное приложение без адресной строки браузера и сможет работать даже при отсутствии интернет-соединения.

### Почему данные остаются только на устройстве?
Ваши личные фотографии, точные координаты и история перемещений никогда не покидают браузер. Приложение использует технологию **IndexedDB** (`navigator.storage.persist()`) и работает в режиме чисто статического SPA. Чтобы перенести историю между компьютером и телефоном, используйте кнопку **«Сохранить бэкап без фото»** (быстрый компактный файл со всеми открытиями и очками) или **«Сохранить бэкап с фото»** в профиле — полученный JSON-файл можно открыть на другом устройстве с автоматическим слиянием без дубликатов.

## 🎮 Как это устроено: игровые механики

- **Ранги и опыт:**
  - Каждый исследованный район: `100 × редкость` XP.
  - Каждый новый регион: `300 × редкость` XP.
  - Новая страна: `1000` XP.
  - Бонус за удалённость от дома (дом выбирается в профиле или кнопкой «Сделать домом» в карточке): опыт за районы, регионы и места умножается на ×1 до 100 км, ×1,5 до 500 км, ×2 до 2000 км и ×3 дальше. Всё внутри домашнего региона — ×1.
  - Открытая достопримечательность: `150 × tier` (150–600 XP) + бонус `+500` XP за объект ЮНЕСКО.
  - Ранги: от *«Домоседа»* до *«Первопроходца»* и *«Легенды»*.
- **Достопримечательности (4 667 объектов):**
  - Природные и культурные памятники по всей России и миру: музеи, храмы, кремли, дворцы, монументы, горы, озёра и заповедники.
  - 981 объект Всемирного наследия ЮНЕСКО (из них 34 в России) и все Семь чудес России (Байкал, Долина гейзеров, Мамаев курган, Петергоф, Собор Василия Блаженного, столбы выветривания Маньпупунёр, Эльбрус).
  - Открытие достопримечательности происходит **только от подтверждённых фото (золото/серебро)** в пределах индивидуального радиуса видимости (от 300 м до 15 км). Ручные отметки не открывают достопримечательность для сохранения честного соревновательного смысла.
  - Карточка достопримечательности с фото Wikimedia Commons, категорией, датой открытия, XP и ссылкой на русскую Википедию.
  - Добавление любого места в личный вишлист в один клик.
- **Редкость территорий:**
  - Рассчитывается по плотности населения на основе пространственных данных Natural Earth. Густонаселённые центры (Москва, Санкт-Петербург, Краснодар) — *Обычные*, а самые суровые и труднодоступные края (Чукотка, Таймыр, Якутия, Ямал) — *Легендарные*.
- **Уровни доказательств:**
  - 🥇 **Золото:** точные координаты из метаданных EXIF снимка или MP4-атомов видео.
  - 🥈 **Серебро:** фотография без GPS, подтверждённая локальной нейросетью CLIP (`Xenova/clip-vit-base-patch32`) путём сопоставления с открытыми снимками Wikimedia Commons вокруг указанной точки.
  - 🥉 **Бронза:** ручная отметка локации без фотоматериалов.
- **Мягкий туман войны:**
  - На масштабах от zoom 7 карта окутана туманом, который плавно рассеивается вокруг центров открытых шестиугольных ячеек Uber H3 (resolution 6).
- **58 достижений в четырёх разделах** (список — `src/services/achievementsConfig.ts`):
  - *Россия* — 5/15/30/50/89 субъектов, все субъекты каждого федерального округа, моря, Арктика, Транссиб, Байкал, Золотое кольцо, Кавказ, республики, районы и «Весь регион».
  - *Мир* — 5…100 стран, 2/4/6 континентов, соседи России, СНГ, Европа, Азия, оба полушария, регионы других стран.
  - *Места* — 10/50/150/400 открытых мест, 3/10/25 объектов ЮНЕСКО, все Семь чудес России, 20 музеев, 20 храмов, 30 природных объектов, достопримечательности в 5 зарубежных странах.
  - *Особые* — фото на высоте 1500/3000/5000 м, ночью и за Полярным кругом.
  - У каждого достижения отображается наглядный прогресс «N / M».
- **Хроника путешествий и итоги года:**
  - Интерактивная лента хроники с автогруппировкой фото в поездки по датам (разрыв до 2 суток) и соседним регионам.
  - Поездки внутри домашнего региона помечаются «дома» и сворачиваются в компактную строку.
  - Клик по карточке поездки центрирует карту и масштабирует её на охват всех точек маршрута через `fitBounds`.
  - Карточки поездок показывают посещённые регионы/страны, число впервые открытых мест и превью до 4 фотографий.
  - Блок «Итоги года» с переключателем лет: новые территории (в т.ч. субъекты РФ), число поездок и дней в пути вне дома, самая дальняя точка от дома, высшая точка маршрутов, крайние регионы (С/Ю/В/З), годовой опыт и мини-гистограмма активности по 12 месяцам.
  - Кнопка «Поделиться итогами» генерирует карточку 1080×1350 на Canvas в фирменном стиле приложения и делится через `navigator.share` или скачивает PNG.

## 🔄 Карта потока данных

```
  Фото / Видео (JPEG, HEIC, MP4, MOV)
                   │
                   ▼
  Параллельная обработка метаданных
    ├─ exifr (GPS, дата, высота, встроенное превью)
    └─ Нативный парсер атомов moov/udta/©xyz
                   │
                   ▼
  Группировка превью по (Дата + H3-7)
    (экономия памяти: 2500 фото → десятки превью)
                   │
                   ▼
  Web Worker пространственного поиска
    ├─ Flatbush R-Tree + Turf.js (район, регион, проверка границ 2 км)
    └─ Flatbush R-Tree достопримечательностей (радиус 300м – 15км)
                   │
                   ▼
  Локальная база данных IndexedDB (Dexie v2)
    ├─ photos, thumbs, marks, achievements, settings
                   │
                   ▼
  Реактивный движок игры и прогресса
    ├─ Расчёт XP, уровней, процентов суши и рангов
    ├─ Счётчики открытых мест и объектов ЮНЕСКО
    └─ Проверка условий достижений
                   │
                   ▼
  Слои визуализации MapLibre GL
    ├─ Монохромная векторная подложка OpenFreeMap
    ├─ Hillshade рельеф Terrarium AWS / Mapzen
    ├─ Заливки посещённых районов/регионов
    ├─ Точки достопримечательностей (зум-зависимый фильтр по tier и UNESCO)
    ├─ Точки и кластеры фотоснимков
    └─ Canvas-оверлей мягкого тумана войны H3
```

## 🛠️ Сборка и обновление пространственных данных

Все векторные границы районов, регионов и достопримечательностей уже подготовлены и включены в репозиторий (`public/data/`). При необходимости их можно пересобрать из первоисточников:

### 1. Границы районов и регионов
```bash
npm run build:data
```
Скрипт `scripts/build-data.mjs`:
1. Скачивает и кэширует в `data-cache/` наборы Natural Earth (страны с точкой зрения РФ `ne_10m_admin_0_countries_rus`, регионы мира `ne_10m_admin_1_states_provinces`, города `ne_10m_populated_places`).
2. Загружает упрощённые полигоны районов geoBoundaries RUS ADM2 и сопоставляет русские названия из OpenStreetMap Overpass API.
3. Добавляет районы Крыма и Севастополя из OSM.
4. Берёт русские названия регионов из Wikidata (кэш `data-cache/wikidata-labels.json`), чистит их и раскладывает спорные территории с точки зрения РФ.
5. Упрощает регионы через `mapshaper`, а контуры стран собирает объединением регионов.

### 2. Каталог достопримечательностей
```bash
npm run build:sights
```
Скрипт `scripts/build-sights.mjs`:
1. Запрашивает через Wikidata SPARQL объекты культурного и природного наследия (музеи, храмы, кремли, дворцы, монументы, природные парки, горы, озёра, объекты ЮНЕСКО) с фильтрацией по sitelinks (порог узнаваемости).
2. Выгружает все объекты Всемирного наследия ЮНЕСКО в России и мире.
3. Дополняет русскоязычными заголовками статей через Wikidata Entity API и описаниями.
4. Присваивает радиусы обнаружения (от 300 м для компактных памятников до 15 км для крупных озёр вроде Байкала) и уровни значимости `tier` (1..4).
5. Кэширует все сырые ответы в `data-cache/sights/` — повторная сборка выполняется полностью офлайн за ~1 секунду.
